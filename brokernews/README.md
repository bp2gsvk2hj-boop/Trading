# Дайджест брокерского рынка

По будням два раза в день (09:00 и 18:00 МСК; новости выходных — в выпуске понедельника) собирает материалы про брокерский бизнес Сбера
и рынок брокерских услуг России и присылает сводку в Telegram.

**Источники:**
- публичные Telegram-каналы — читаются через `t.me/s/<канал>`, вход в Telegram не нужен;
- Google Новости — по запросам из настроек;
- RSS-ленты СМИ.

**Как устроен отбор:**
- источники в два уровня: отраслевые (НАУФОР, Банк России, Мосбиржа, СберИнвестиции, ВТБ,
  Финам, Frank Media, Банкста, Интерфакс, РБК и ленты СМИ) и рыночные каналы владельца —
  из них берутся только посты про СберИнвестиции (посевы, промо);
- первичное сито по деловой лексике отрасли: бренд брокера проходит только вместе со словами
  о бизнесе (клиенты, счета, тарифы, сервисы, лицензии, сделки); аналитика, прогнозы, котировки,
  размещения, IPO, страхование и т. п. отсекаются сразу; сайты рыночной аналитики (БКС Экспресс
  и др.) — только материалы про СберИнвестиции;
- редактор ChatGPT (gpt-5) проверяет каждый материал тремя вопросами: о брокерском бизнесе ли
  это; новое ли это существенное событие; зачем это руководителю СберИнвестиций. Помнит
  опубликованное за 7 дней. Выпуск пишет gpt-5-mini: 0–10 пунктов, без минимума;
- без ответа редактора в канал не уходит ничего; владельцу — одно служебное сообщение;
- служебные сообщения только о критичном: не отвечает большинство источников или редактор.

**Проверка качества:** `python3 -m brokernews review --hours 24` присылает владельцу
(не в канал) черновик выпуска, что взято и почему, и что близко, но отклонено.

**Куда приходит:**
- в Telegram-канал для коллег (`BROKERNEWS_CHAT_IDS`), если он задан. Бот робота публикует туда
  от имени канала, торговые уведомления в канал не попадают. Чтобы добавить читателей, пригласите их в канал;
- иначе в чат торгового робота;
- в архив на странице `http://<IP сервера>:8080/news/`, рядом с «Помощником трейдера».

Без внешних зависимостей, нужен только Python 3.11+. Запросы идут через curl по выходам VPN
на сервере (`TELEGRAM_PROXY`, иначе `127.0.0.1:10810/10811`), а при их недоступности — напрямую.

## На сервере

Ставится вместе с роботом той же командой (см. `server/install.sh`). Установщик спрашивает
ключ OpenAI и канал для рассылки и хранит их в `/etc/trading-robot.env`
(`OPENAI_API_KEY`, `BROKERNEWS_CHAT_IDS`; несколько получателей — через запятую).

    systemctl start trading-robot@news          # прислать дайджест сейчас
    journalctl -u trading-robot@news -n 50      # журнал
    cd /opt/trading && sudo -u robot python3 -m brokernews channels   # какие каналы читаются
    cd /opt/trading && sudo -u robot python3 -m brokernews run --hours 24 --dry-run  # показать, не отправлять

## Настройки

Настройки лежат в `brokernews.toml` в корне репозитория: каналы, запросы, ленты,
ключевые слова, модель и инструкция для ChatGPT. Перед каждым запуском сервер делает
`git pull`, поэтому правка в main начинает действовать со следующего дайджеста.
Состояние (что уже отправлено, здоровье источников) хранится в `state/brokernews.db`.

Пропущенная новость → пример в `tests/brokernews_cases.toml` (текст и раздел). Тесты
проверяют, что ключевые слова ловят все примеры, и пропуск не повторится.
